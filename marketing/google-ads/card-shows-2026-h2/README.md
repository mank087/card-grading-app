# Card-show Search campaigns — Google Ads Editor import (H2 2026)

Generated by `scripts/google-ads-card-shows-import.ts` from the `card_shows` table (active, US, not removed). One Search campaign per show, running from **10 days before the first day through the last day of the show**, targeting the show's city (and metro when the venue is in a suburb) plus the state, landing on that show's page `/card-shows/{slug}`.

## Budget

$8/day per campaign while it runs. Roughly 4-6 shows overlap at any time, so expect **$30-50/day** in September-October and less in December. Total across all 30 windows is about $3,100. Raise the cap on the big ones (Pokémon Worlds, Philly Show, Dallas, Chicago Sports Spectacular, NASH-IONAL) if they show impression share loss.

## After import

1. Review the location matches Editor picked for each campaign (Locations tab); fix any it mapped to the wrong "Oaks" or "Portland".
2. The three campaigns whose window already started (Pokémon Worlds, Collect-A-Con Richmond and Charlotte, Culture Collision) go live on Post.
3. Add the campaigns to the same conversion goals as the rest of the account (Purchase primary, Signup secondary) once GA4 import is done.
4. Every show page carries the CARDSHOW offer; make sure the promo code is live in Stripe before the first campaign serves.
5. Regenerate whenever the `card_shows` table changes: `DOTENV_CONFIG_PATH=.env.local npx tsx scripts/google-ads-card-shows-import.ts`. Re-importing updates existing campaigns by name and adds new ones.

## Copy rules

Claims are limited to what the show page says (dates, venue, highlights, the CARDSHOW offer) and DCM's standard benefits. No "pre-grade / pre-check / second opinion" language, no grader names, no accuracy claims. "Check centering before buying" describes using DCM at the table, which the show pages already promote.

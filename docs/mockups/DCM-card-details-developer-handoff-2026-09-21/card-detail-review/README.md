# Card detail page — isolated review concept

Open `index.html` directly, or run `node serve.cjs` in this directory and visit http://127.0.0.1:4317.

This standalone redesign uses copies of existing Lugia card artwork, the Heritage label, DCM logo, and Label Studio holder backgrounds. No production page, shared component, dependency, or application configuration was modified. The original Pokémon detail client is copied into `reference/CardDetailClient.original.tsx.txt` for comparison; it is not imported or executed.

Try the three holder switches, four label styles, five detail sections, subgrade evidence, sample label downloads, image export, and InstaList review dialog. Supply links go to the existing DCM shop. Backend-dependent actions are local previews. Only sample artwork and a text report can download; production print PDFs are not connected.

The Lugia image and Heritage grade 7 label are existing artwork. Pricing, price history, subgrades, findings, portfolio figures, connection status, and listing information are illustrative. No back photo is available in this sample, and the Back action explains that limitation. Sample downloads are watermarked and are not calibrated print files.

All work for this concept lives in this directory. Google Fonts is optional; local font fallbacks are included. The rest of the preview assets are local.
